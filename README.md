# Прикрепление партнёра к партнёрским лидам (amoCRM)

Заменяет связку Albato «Поиск лидов партнера» (479713).

**Что делает.** Раз в 15 минут берёт новые лиды в воронке «Партнерство: лидогенерация» (11489426) и проверяет, партнёрские ли они. Лид партнёрский, если `utm_source` или `last_utm_source` равен `partner` или если в поле `referrer` стоит код партнёра (так приходят лиды из виджета).

Для каждого партнёрского лида скрипт:

1. Берёт код партнёра из `utm_medium`, затем из `last utm_medium`, затем из `referrer`.
2. Ищет сделку партнёра в воронке «Партнерство» (8923730). Код сверяется с ID сделки, с полем «referrer партнера» и с полем «utm medium партнера». Поэтому находятся и партнёры, у которых код не совпадает с ID сделки (PRMOnline: код 31358193, сделка 33583531).
3. Записывает компанию партнёра в поле «Партнер» (707209) и код партнёра в поле «referrer партнера» (705296), привязывает к лиду основной контакт партнёра. У лидов, где партнёр уже прикреплён, а «referrer партнера» пустой, дозаполняет это поле и тег.
4. Оставляет примечание «⛳️ Лид привлечен партнером: <ссылка на сделку партнёра> …» и ставит теги `partner_linked` и тег с названием компании партнёра. Если компании нет или у неё пустое название, вместо него ставится полное имя контакта партнёра.
5. Если кода нет или партнёр не найден, ставит задачу (как раньше в Albato) и тег `partner_not_found`.

Лиды с тегом или с уже заполненным полем «Партнер» повторно не обрабатываются.

## Настройка

1. **Settings → Secrets and variables → Actions → Secrets:** добавить `AMO_TOKEN` (долгосрочный токен amoCRM).
2. **Actions → «Прикрепление партнёра к лидам» → Run workflow**, режим `dry-run`. В логе будет видно, что скрипт сделал бы.
3. Если всё верно: **Variables** → `PARTNER_LINK_AUTO_APPLY` = `true`. После этого запуски по расписанию начнут записывать в amo.
4. Выключить связку в Albato, чтобы примечания не дублировались.

Ручной запуск: режим `apply`, окно `days` (по умолчанию 3) или ID одного лида.
